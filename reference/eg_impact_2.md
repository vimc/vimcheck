# Second example of impact data

Second example of impact data

## Usage

``` r
eg_impact_2
```

## Format

### `eg_impact_2`

A data frame with 4 rows and 6 columns:

- country:

  Example country identifier.

- year:

  Year.

- birth_cohort:

  Numeric for the birth year.

- burden_outcome:

  Outcome identifier.

- impact:

  Numeric for impact.

- short_name:

  Example identifier.
