# Save pressure-testing diagnostics to local file

Save pressure-testing diagnostics data.frames to local compressed files
in the `.Rds` format. Input data.frames are generated by other package
functions and are not checked here.

## Usage

``` r
save_outputs(
  missing_in_current,
  missing_deaths,
  missing_dalys,
  changes_deaths,
  changes_dalys,
  subregional_flags_deaths_camp,
  subregional_flags_deaths_rout,
  subregional_flags_dalys_camp,
  subregional_flags_dalys_rout,
  output_dir = here::here("outputs")
)
```

## Arguments

- missing_in_current:

  A data.frame.

- missing_deaths:

  A data.frame that is the output of
  [`filter_invalid_trajectories()`](https://vimc.github.io/vimcheck/reference/filter_impact_data.md)
  with the outcome `"deaths_averted"`.

- missing_dalys:

  A data.frame that is the output of
  [`filter_invalid_trajectories()`](https://vimc.github.io/vimcheck/reference/filter_impact_data.md)
  with the outcome `"dalys_averted"`.

- changes_deaths:

  A data.frame that is the output of
  [`flag_large_diffs()`](https://vimc.github.io/vimcheck/reference/flag_large_diffs.md)
  with the outcome `"deaths_averted"`.

- changes_dalys:

  A data.frame that is the output of
  [`flag_large_diffs()`](https://vimc.github.io/vimcheck/reference/flag_large_diffs.md)
  with the outcome `"dalys_averted"`.

- subregional_flags_deaths_camp:

  A data.frame that is the output of
  [`compare_natl_subreg()`](https://vimc.github.io/vimcheck/reference/compare_natl_subreg.md)
  with the outcome `"deaths_averted_rate"` for the `"campaign"` activity
  type.

- subregional_flags_deaths_rout:

  A data.frame that is the output of
  [`compare_natl_subreg()`](https://vimc.github.io/vimcheck/reference/compare_natl_subreg.md)
  with the outcome `"deaths_averted_rate"` for the `"routine"` activity
  type.

- subregional_flags_dalys_camp:

  A data.frame that is the output of
  [`compare_natl_subreg()`](https://vimc.github.io/vimcheck/reference/compare_natl_subreg.md)
  with the outcome `"dalys_averted_rate"` for the `"campaign"` activity
  type.

- subregional_flags_dalys_rout:

  A data.frame that is the output of
  [`compare_natl_subreg()`](https://vimc.github.io/vimcheck/reference/compare_natl_subreg.md)
  with the outcome `"dalys_averted_rate"` for the `"campaign"` activity
  type.

- output_dir:

  A writeable directory. Defaults to "./outputs".

## Value

None. Called for the convenience side-effect of saving data.frames as
`.Rds` format.
